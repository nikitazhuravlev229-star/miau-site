# CLAUDE.md — правила работы с сайтом MIAU

Полное описание сайта — в README.md. Прочитай его перед первой правкой.

## Стек
Статический HTML/CSS/JS без сборки. Не переводить на фреймворки, не добавлять npm-сборку. Внешние библиотеки лежат в `assets/` (Lenis, Leaflet). Шрифты — Google Fonts.

## Жёсткие правила бренда
- Цвета только `#2A030C` (вино), `#680517` (бордо), `#EFE4D6` (беж) и их прозрачность. Никакого золотого (`#C9A46A` удалён намеренно), розового, белого, новых цветов.
- Шрифты только Unbounded (заголовки, вес 300) и Manrope (текст). Никакого `font-style: italic`.
- Не добавлять блоки, подписи, украшения и дубли, о которых не просили. Каждый элемент должен иметь смысл.
- Логотип не перерисовывать — использовать файлы `emblem-*.webp` и `logo-miau-beige.svg`.
- Без упоминаний открытия и дат открытия.
- Не выдумывать факты о студии (цены, правила, услуги, имена). Неизвестное — меткой в квадратных скобках.
- Обращение к посетительнице на «ты».

## Как править
- Шапка и подвал продублированы во всех 8 HTML-файлах — менять везде.
- Общие стили компонентов — `assets/ui.css`, анимации — `assets/fx.css`, базовые классы типографики — `<style>` в каждом HTML.
- Кнопки записи: `data-book` (+ `data-dir`, `data-svc`), сертификата: `data-cert` (+ `data-sum`). Логика — `assets/ui.js`.
- Анимации появления: классы `.split` (авто для `.h1/.d1/.h2.rv`), `.zoom`, `.stg`, `.draw`, `.fade`; прогресс прокрутки — `data-scroll="pass|pin"` → CSS-переменная `--p`.
- Всё скрытое для анимаций — только под `.js-fx`, чтобы без JS и при reduced motion контент был виден.
- После правок CSS/JS обновить `?v=` в ссылках (см. README).

## Проверка перед пушем
- Открыть через `python3 -m http.server` на 1440 px и 390 px, прокрутить страницу до конца.
- Нет горизонтальной прокрутки, нет ошибок в консоли, анимации доезжают до конца.
- Формы: пройти запись и сертификат до сводки, проверить ошибки пустых полей.
- Пуш в `main` → GitHub Pages обновится сам.
