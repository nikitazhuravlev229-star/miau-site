# MIAU — сайт пространства красоты, тела и души

Статичный многостраничный сайт: HTML + CSS + немного JavaScript, без сборщика и фреймворков.
Москва, Фрунзенская набережная, 46. Открытие — начало декабря 2026.

## Как открыть

```
cd miau-site
python3 -m http.server 8000
# открыть http://localhost:8000
```

Можно открыть `index.html` двойным кликом. Видео и шрифты надёжнее работают через локальный сервер.

## Дизайн-система

**Цвета — только 4:**

| Роль | HEX |
|---|---|
| Беж — основной фон, текст на тёмном | `#EFE4D6` |
| Бургунди — бренд, текст на светлом, кнопки | `#680517` |
| Вино — тёмные секции, подвал | `#2A030C` |
| Золото — только нить и точки-акценты | `#C9A46A` |

Прозрачности (`rgba(104,5,23,.25)` для линий и т. п.) — производные от этих цветов. Новых цветов не добавлять.

**Шрифты — только 2 (Google Fonts):**
- Cormorant Garamond 400 / italic — все заголовки, названия направлений (капсом, разрядка .16em).
- Montserrat 400 / 500 — текст, кнопки, меню.

**Шкала размеров (классы в `<style>` каждой страницы):**

| Класс | Размер | Где |
|---|---|---|
| `.d1` | clamp(52px, 6.6vw, 92px) | заголовок первого экрана главной |
| `.h1` | clamp(46px, 5.6vw, 76px) | заголовок внутренней страницы |
| `.h2` | clamp(34px, 4.2vw, 56px) | заголовок блока |
| `.h3` | 28px (24 в таблицах) | подзаголовок |
| `.dir` | 26px, капс | BODY / ENERGY / … |
| `.lead` | clamp(17px, 1.35vw, 19px) | вводный текст |
| `.body` | 15px | основной текст |
| `.small` | 13px | подписи |

**Сетка и отступы:** `.wrap` — max-width 1440, поля clamp(20px, 4vw, 56px). `.sec` — вертикальный отступ блока clamp(64px, 7vw, 96px), на телефоне 56px. Между фото 16px, между карточками 12–16px.

**Кнопки:** `.btn` (пилюля, 48px), `.btn-cream` (на тёмном), `.btn-wine`, `.btn-ghost` / `.btn-ghost-d` (контур).

**Фирменная деталь:** тонкая бордовая нить с золотой точкой из буклета. На ней «висят» знаки направлений (`assets/sign-*.svg`), она стоит над финальными призывами.

## Анимации (ориентир — o-p-e-n.com и sos-senseofself.com)

- Первый экран: золотая нить прорисовывается сверху вниз (`.load-thread`), заголовок и текст проявляются с задержкой (`.load-1`, `.load-2`), фон медленно приближается (`.load-img`).
- При скролле: заголовки `.h2.rv` выезжают снизу, фото `.zoom` раскрываются шторкой сверху (clip-path). Знаки направлений `.draw` дорисовываются по нити.
- Сделано на CSS `animation-timeline: view()`. Где браузер его не поддерживает (Firefox, старый Safari), `assets/site.js` включает тот же эффект через IntersectionObserver.
- Наведение: фото чуть приближаются, у ссылок меню вырастает подчёркивание.
- Сцена «Руки. Масло. Свечи.» на втором этаже — `site.js`, меняет кадр по прокрутке.
- Всё отключается при `prefers-reduced-motion: reduce`.

## Файлы в assets/

- `logo-miau-beige.svg` — логотип (вектор с оригинала заказчика).
- `sign-body/energy/beauty/connection/soul.svg` — знаки пяти направлений, нарисованы по мотивам буклета.
- `flower_cream.svg`, `flower2_wine.svg` — знак «цветок» из пяти кругов (сертификаты, favicon).
- `hero.mp4` + `hero_poster.jpg` — видео первого экрана, 14 с, 1920×1080, 2,4 МБ, без звука.
- `*.jpg` — фото, тонированные в палитру сайта. `m-*.jpg` — плитки из мудборда заказчика.
- `site.js` — видео, сцена второго этажа, запасные анимации, закрытие мобильного меню.

**Источники и права:** фото — Unsplash (Unsplash License), видео — Pexels (Pexels License): бесплатно, можно в коммерческих целях, указывать автора не обязательно. Логотип, мудборд и знаки — материалы заказчика. Все фото людей временные: их заменят на съёмку площадки и команды.

## Что не заполнено (метки в [квадратных скобках])

- Телефон, часы работы, Telegram, WhatsApp, e-mail для обращений.
- Реквизиты (ООО/ИП, ИНН, ОГРН) в подвале.
- Цены и длительность всех услуг.
- Система онлайн-записи: кнопки «Записаться» сейчас ведут на `kontakty.html`.
- Тексты пяти документов (готовит юрист, структура разделов есть).
- Имена и портреты специалистов, реальные работы и отзывы.
- Даты практик, как подняться на второй этаж, что взять с собой.
- Приложение MIAU — пока «скоро».

## Правила для доработки

- Название всегда латиницей: MIAU (не «Мяу»).
- Обращение на «ты», коротко и конкретно, без пафоса.
- Не больше 2 шрифтов и 4 цветов. Белого фона нигде нет.
- CSS сейчас повторяется в `<style>` каждой страницы. При переносе на CMS вынести его в один файл `styles.css`.
