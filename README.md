# MIAU — сайт пространства красоты, тела и души

Москва, Фрунзенская набережная, 46. Женское пространство: бьюти на первом этаже, массаж и практики на втором.
Основательница — Ирина.

- Живая версия: https://nikitazhuravlev229-star.github.io/miau-site/
- Репозиторий: https://github.com/nikitazhuravlev229-star/miau-site (ветка `main`, GitHub Pages публикует её сам за ~1 минуту после пуша)
- Сайт — обычный статический HTML/CSS/JS, без сборки и без фреймворков. Открывается любым локальным сервером.

## Как запустить у себя

```bash
cd miau-site
python3 -m http.server 8000
# открыть http://localhost:8000
```

Двойной клик по index.html тоже откроет, но карта и видео лучше работают через сервер.

## Как выложить изменения

1. Попросить у владельца доступ к репозиторию (Settings → Collaborators) или сделать форк.
2. `git add -A && git commit -m "…" && git push` в ветку `main`.
3. Через минуту изменения на сайте. Если браузер показывает старое — Cmd+Shift+R.
4. После правок CSS/JS поднять номер версии в ссылках, чтобы у посетителей не застрял старый кэш:
   `sed -i -E "s/\?v=[0-9]+/?v=$(date +%s)/g" *.html` (на Mac: `sed -i '' -E ...`).

**Перетекание (ui.css, раздел «Перетекание»).** Видео первого экрана растворяется в беж; классы `.fl` + `.fl-in` / `.fl-out` делают бордовую секцию с плавным переходом из бежа и обратно; `.soft` растворяет края фото в фоне. Подвал тоже входит из бежа градиентом.

Так обработаны manicure-work, talk, power-yoga и 4 фото Ирины; остальные стоковые пришли уже тонированными, их переобработать нельзя — заменить после съёмки.

## Дизайн-система

**Цвета — только три. Золотого, розового и белого нет нигде (решение заказчика).**

| Роль | HEX |
|---|---|
| Вино — тёмные фоны, текст на светлом | `#2A030C` |
| Бордо — бренд, кнопки, акценты | `#680517` |
| Беж — основной фон, текст на тёмном | `#EFE4D6` |

**Шрифты (Google Fonts):**
- Заголовки — **Unbounded 300** (широкий геометрический). Курсива у шрифта нет — `font-style: italic` не использовать.
- Текст, кнопки, меню, девизы — **Manrope 400/500/600**.

**Классы типографики** (заданы в `<style>` каждой страницы, мобильные размеры в `assets/fx.css`):
`.d1` — главный заголовок первого экрана, `.h1` — заголовок страницы, `.h2` — заголовок блока, `.h3` — подзаголовок, `.lead` — вводный абзац, `.body` — текст, `.small` — подписи.

**Сетка:** `.wrap` — на всю ширину экрана с полями `clamp(20px, 4.5vw, 96px)`. `.sec` — вертикальные отступы блока.
**Кнопки:** `.btn` + `.btn-cream` (беж на тёмном), `.btn-wine` (бордо на светлом), `.btn-ghost` (контур на тёмном), `.btn-ghost-d` (контур на светлом).

**Логотип:**
- Круглый «лучистый» знак с MIAU внутри: `assets/emblem-wine.webp` (бордо), `assets/emblem-cream.webp` (беж). Интро, подвал, мобильное меню, сертификат, 404.
- Надпись MIAU `assets/logo-miau-beige.svg` — в шапке и огромная надпись в подвале. Эмблему в кружке в шапку не ставим (решение 22.11).
- `assets/favicon.png` — иконка вкладки.

**Знаки направлений:** `assets/sign-body|energy|beauty|connection|soul.svg` — перерисованы по мотивам буклета; заказчик хочет заменить на оригиналы из буклета, когда пришлёт файлы.

## Файлы скриптов и стилей

| Файл | Что делает |
|---|---|
| `assets/fx.css` | Анимации появления: слова заголовков выезжают из-под маски, фото открываются шторкой, группы появляются по очереди, параллакс, цитата из размытия, сцена «Можно задержаться», первый экран на высоту экрана, мобильные размеры текста. Работает только при классе `js-fx` на `<html>`. |
| `assets/site.js` | Видео, плавная прокрутка (Lenis), деление заголовков на слова, появление при прокрутке (IntersectionObserver), прогресс прокрутки `--p` для `[data-scroll]`, мобильное меню. |
| `assets/ui.css` + `assets/ui.js` | Компоненты: панели направлений, лента практик, цитата, карточка сертификата, боковая панель записи и сертификата, карта, подвал. |
| `assets/lenis.min.js` | Плавная прокрутка (Lenis 1.3). |
| `assets/leaflet.js/.css` | Карта (Leaflet 1.9.4 + OpenStreetMap), подключена на главной и в контактах. |

Интро-логотип: CSS и маленький скрипт в `<head>` и в начале `<body>` каждой страницы. Показывается раз за сессию браузера (`sessionStorage`). При «уменьшить движение» в системе — все анимации выключены, контент виден сразу.

## Формы записи и сертификата

- Любая ссылка с атрибутом `data-book` открывает панель записи: направление → услуга → день (2 недели вперёд) и время (утро/день/вечер) → имя, телефон с маской, как связаться, комментарий, согласие на ПД → сводка.
- `data-cert` открывает оформление сертификата: сумма (5/10/15/20 тыс. или своя) или направление → кому, от кого, пожелание, как получить → контакты → сводка. Превью сертификата меняется вживую.
- Предвыбор из кнопки: `data-dir="body"`, `data-svc="Йога"`, `data-sum="15000"`.
- **ВАЖНО: отправка не подключена.** Заявка собирается, посетитель видит «Заявка у нас», но никуда ничего не уходит (в консоли пишется `MIAU: заявка собрана…`). Подключить: в `assets/ui.js` задать `MIAU.endpoint = 'https://…'` — туда уйдёт POST с JSON `{type, data, page, at, consent}`. Варианты: Telegram-бот (через свой мини-сервер или Cloudflare Worker, токен бота нельзя класть в код сайта), CRM, Formspree.

## Ассистент (чат) и заявки в Telegram
- Окно чата: `assets/chat.js`, стили в конце `assets/ui.css` (блок «ассистент»). Подключён на всех страницах после `ui.js`.
- Запись и сертификат чат собирает сам, по шагам (направления, услуги, день, время, имя, телефон, связь, согласие) и шлёт заявку в `MIAU.endpoint` — тем же JSON, что форма, плюс `source: "chat"` и `dialog` (последние реплики).
- Свободные вопросы уходят в `MIAU.chatEndpoint`. Пусто — бот отвечает без нейросети: адрес, направления, переход к записи.
- Сервер: `tools/assistant/index.js` — облачная функция (Yandex Cloud Functions, Node 18+). Один адрес: `{messages}` → GigaChat, заявка → сообщение в Telegram. Ключи только в переменных окружения функции (GIGACHAT_KEY, GIGACHAT_SCOPE, TG_TOKEN, TG_CHAT, ALLOW_ORIGIN). В код сайта ключи не класть.
- Для GigaChat положить рядом с index.js сертификат НУЦ Минцифры (`russian_trusted_root_ca.pem`, с gosuslugi.ru/crt) и задать `NODE_EXTRA_CA_CERTS=./russian_trusted_root_ca.pem`.
- Бот отвечает только по `tools/assistant/kb.md`. Всё в [скобках] он не озвучивает и отправляет к администратору. Новые факты от Ирины вписывать туда.
- Подключение: вписать адрес функции в `MIAU.endpoint` и `MIAU.chatEndpoint` в начале `assets/ui.js`, обновить `?v=`.
